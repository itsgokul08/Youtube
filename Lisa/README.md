# LISA "Tarantino" Short

| Folder | Contents |
|---|---|
| `Voiceover/` | VO audio (ElevenLabs) |
| `Clips/` | Flow clips `S1.mp4`–`S6.mp4` (prompts in `Script/flow_prompts.md`) |
| `Graphics/` | Thumbnail and stills |
| `SFX/` | Tick, whoosh, impact and ping sounds |
| `Script/` | Script, timings, loop map, Flow prompts |
| `Edit/` | `render.py`, which builds the whole edit with ffmpeg |
| `Export/` | Finished Short (1080×1920, 30 fps) |

Re-render after adding clips: `python3 Lisa/Edit/render.py`
